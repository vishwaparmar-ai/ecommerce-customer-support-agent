# Return Policy

## Eligibility Window

Items purchased from ShopFlow may be returned within **10 days of actual delivery**. The
return window is calculated from the date the shipment is marked as delivered, not the
order date. Requests submitted after this window has closed will be rejected as expired.

## Delivery Requirement

An order must be marked **Delivered** before a return can be requested. Orders that are
still Processing, Shipped, or Out for Delivery are not eligible for return — the item
must have actually reached the customer first.

## Non-Returnable Categories

The following product categories are not eligible for return under any circumstances,
due to hygiene, safety, or perishability concerns:

- Grocery

All other categories (Electronics, Clothing, Home & Kitchen, Books, Sports & Fitness,
Beauty, Toys) are returnable within the standard window, subject to the conditions below.

## One Return Per Order

Only one return request may be submitted per order. If a return request already exists
for an order — regardless of its current status (requested, under review, approved,
rejected, or completed) — a new return request for the same order cannot be created.

## Return Request Process

1. Customer submits a return request with a reason.
2. The system validates: order ownership, delivery status, return window, product
   category eligibility, and duplicate-request check.
3. If all checks pass, the return is created in **Requested** status.
4. Support staff move the return through Under Review → Approved (or Rejected) →
   Pickup Scheduled → Received → Completed.
5. Once a return reaches **Completed**, it becomes eligible for a refund — see the
   Refund Policy for details.

## Acceptable Return Reasons

Common reasons customers may cite include:

- Item damaged on arrival
- Wrong item received
- Product not as described
- Changed my mind
- Size or fit issue
- Defective or not working

## Rejected Returns

A return may be rejected if it falls outside the return window, involves a
non-returnable category, or does not meet the company's quality/condition standards
for the returned item. Rejected returns are not eligible for a refund.
