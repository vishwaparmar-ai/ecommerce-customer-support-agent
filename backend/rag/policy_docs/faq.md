# Frequently Asked Questions

## Orders

**How do I check my order status?**
Log in and go to your order details page, or ask the support assistant "where is my
order?" — it will look up the live status directly.

**Can I change my order after placing it?**
Item quantities and products cannot be changed once an order is placed. You can cancel
the order (if it's still Pending, Confirmed, or Processing) and place a new one instead.

**Can I change my shipping address after placing an order?**
Only while the order is still in the Preparing stage. Contact support for address
changes on orders already in later stages.

## Cancellations

**How do I cancel my order?**
You can cancel an order yourself as long as it is still Pending, Confirmed, or
Processing. Once it has shipped, self-service cancellation is no longer available —
see the Cancellation Policy.

**Will I get a refund if I cancel a paid order?**
Yes — if payment had already been collected, cancelling the order automatically
refunds the full amount.

## Returns

**How long do I have to return an item?**
10 days from the date your order was actually delivered — see the Return Policy for
full details.

**Can I return everything I buy?**
Most categories are returnable within the window. Grocery items are not eligible for
return under any circumstances.

**Can I submit more than one return for the same order?**
No — only one return request is allowed per order.

## Refunds

**When will I get my refund?**
Once your return is marked Completed, a refund is issued for the full payment amount,
typically within 5–7 business days — see the Refund Policy.

**Can I get a partial refund?**
Not currently — refunds cover the full amount of the original payment.

## Shipping

**What if my order is delayed?**
See Delivery Exceptions — a delayed shipment is still on its way; the return window
will start from the actual delivery date, not the original estimate.

**What if my order is marked lost?**
Contact support — lost shipments are resolved with either a replacement order or a
full refund.

## Support

**How do I talk to a real person?**
Just ask — any request for a human agent is escalated immediately, no need to
navigate a menu.
