# Cancellation Policy

## When an Order Can Be Cancelled

An order can be cancelled by the customer only while it is in one of the following
statuses:

- **Pending**
- **Confirmed**
- **Processing**

Once an order has moved to **Shipped**, **Out for Delivery**, or **Delivered**, it can
no longer be cancelled through self-service — at that point, the customer should
instead request a return (if delivered) or contact support (if already shipped but not
yet delivered).

## Ownership

Only the customer who placed the order can cancel it. A cancellation request against an
order that does not belong to the requesting customer will be rejected.

## What Happens on Cancellation

When an order is cancelled:

1. All stock reserved for the order's items is returned to inventory.
2. The order status is set to **Cancelled**.
3. If payment had already been collected (status: Paid), the amount is refunded and
   the payment status is updated to **Refunded**.
4. If payment had not yet been collected or had failed, no refund action is needed.

## Cancellations After Shipping

Orders that have already shipped cannot be cancelled through the standard cancellation
flow, even if they have not yet been delivered. Customers wishing to reject an
in-transit shipment should contact support, who can coordinate a return-to-sender with
the carrier or advise the customer to refuse delivery and request a return once (if)
the item is returned to the warehouse.

## Repeated Cancellations

There is currently no limit on how many orders a customer may cancel, but a pattern of
frequent cancellations after shipment may be flagged for manual review by support staff.
